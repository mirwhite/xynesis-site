# Xynesis Consulting — Website

Homepage for Xynesis Consulting (capabilities overview).

`index.html` is a single static page (fonts load from Google Fonts). It is responsive, so it works on desktop and mobile, and can be opened directly in a browser or served as-is by any static host.

## Publishing with GitHub Pages

Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)`.
